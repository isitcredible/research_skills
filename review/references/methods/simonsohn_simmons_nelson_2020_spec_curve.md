# Specification curve analysis — Simonsohn, Simmons & Nelson (2020)

Working distillation of Uri Simonsohn, Joseph P. Simmons and Leif D.
Nelson, "Specification Curve Analysis", *Nature Human Behaviour* 4
(2020): 1208–1214. The source PDFs (not distributed with the skill):
`Simonsohn_Simmons_Nelson_2020_SpecCurve_NHB.pdf` (the **published
article, hand-corrected author copy** from urisohn.com — 9 typeset
pages) and `..._supp.pdf` (the 25-page Supplementary Information —
Supplementary Notes 1–5, which carry the observational-data resampling
and the false-positive-correction demonstration).

## The three steps (paper, §"Conducting specification curve analysis")

1. **Define the reasonable-specification set** — all combinations of
   analytic choices that are *theoretically justified, statistically
   valid and non-redundant* (their criteria — "reasonable" is a claim
   about the joint set, and the enumeration is itself the researcher
   degree of freedom the curve can't see).
2. **Estimate them all and display the specification curve** — ranked
   estimates with the spec choices mapped underneath, so readers can
   see which decisions are consequential.
3. **Joint inference across the curve** — three test statistics:
   (i) the **median estimated effect** across all specifications,
   tested against its under-null distribution; (ii) the **share of
   specifications significant in the predicted direction**, tested
   against its under-null share; (iii) the **Stouffer average Z**
   across all specifications — more efficient than the share (it keeps
   the p-values continuous), but SSN propose reporting both (ii) and
   (iii).

## How the under-null distribution is built — the load-bearing detail

The three statistics have no analytic null distribution (specifications
are neither independent nor in one model), so the null is generated by
**resampling**: shuffle the treatment column(s) — e.g., the hurricane's
name — re-estimate *all* specifications on each shuffled dataset (1,728
specs × 500 shuffles in their example), and take the distribution of
the test statistics across shuffles. The only assumption is
**exchangeability** (any unit could have received the shuffled
treatment), so the p-values are 'exact', not asymptotic. For
observational (non-experimental) data the shuffle construction is
subtler — see Supplementary Notes 1–5 before adapting it.

Two implications the abstract does not carry:

- **Joint inference is self-correcting for spec-level violations.**
  Because the null distribution is resampled rather than assumed,
  specifications with inflated false-positive rates do not inflate the
  joint test — Supp. Note 4 shows a curve built on Poisson
  regressions each with >40% per-spec false-positive rate still yields
  the nominal 5% joint rate. A spec curve is *more* forgiving of a bad
  spec than the spec itself is — which also means a "significant" joint
  curve can coexist with no individually trustworthy spec.
- **Sign-dependence is expected, not damning.** Specifications are not
  independent, so under the null a shuffled dataset will mostly show a
  *dominant sign* — don't read a same-sign curve as a violation; the
  joint tests handle it.

## Review use

- Where a curve exists (the paper's own, or one a run chooses to build —
  no stage requires it): the systematic version of the
  author-avoided-specs check — enumerate the defensible spec space,
  run it, and test whether the mass above the threshold exceeds the
  under-null distribution. The three statistics answer different
  questions (typical magnitude / fraction surviving / aggregate
  evidence) — report which was used.
- `claims`: calibrates "how robust is robust" — SSN replaces
  "fragile to specification choice" with a testable statement, and
  their three worked applications (one robust, one weak, one null)
  are the calibration points.
- The caveat to carry: the curve enumerates the *declared* reasonable
  set — the identification-threatening spec the authors never
  classified as reasonable is invisible to it. Audit the enumeration,
  not just the curve.
